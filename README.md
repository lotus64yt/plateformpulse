# Plateform pulse

Never wanted to really know the statistics of your trip on the IDFM rail network? No? Well in case you didnt wanted your wrong you need it :)
Here you go plateformpulse, a simple website that will give you the statistics of your daily trips or even just any trip you want in the past and bake you a nice Spottify Wrapped like sumarry.

## Installation

You must have nodejs, pnpm, go and `make` installed on your machine.

```bash
git clone https://github.com/lotus64yt/plateformpulse
cd plateformpulse
make install
```

Start the server:

```bash
make backend
make frontend
```

Start the dev server:

```bash
make dev
```

Have fun and enjoy your statistics!
